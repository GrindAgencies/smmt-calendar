Drop your source art here for `npm run assets`:

- `icon.png`  — square, ideally **1024×1024** (a 512 starter copied from the repo
  is here; replace with 1024 for crisp store icons).
- `splash.png` — optional, **2732×2732**, logo centered on `#0b0f1a`.

Then run (from the `native/` folder):  `npm run assets && npx cap sync`
